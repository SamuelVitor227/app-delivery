# App Delivery

Aplicativo de delivery mobile desenvolvido com React Native + Expo.

## Stack

- React Native 0.88 + React 19.3
- Expo SDK 58 com expo-router (file-based routing)
- TypeScript
- @expo/vector-icons (MaterialIcons)

## Telas

| Rota | Tela |
|------|------|
| `/` | Home — listagem de restaurantes e categorias |
| `/explore` | Buscar (em desenvolvimento) |
| `/cart` | Carrinho — itens, quantidades, resumo |
| `/checkout` | Checkout — endereço, pagamento, confirmação |

## Como rodar

```bash
npm install
npx expo start
```

- Pressione `a` para Android, `i` para iOS, `w` para Web.
- Use o app **Expo Go** no celular para testar via QR code.
